# Исправления генератора сканвордов и стрелок

## Дата: 2026-03-01

## Проблема 1: Возврат к строгой логике пересечений

### Что было не так:
После предыдущих изменений генератор позволял размещать слова без пересечений, что приводило к разрозненной структуре сканворда.

### Что исправлено:
- **Файл**: `src/services/wordGenerator.ts`
- **Изменения**:
  - Убрана fallback логика "размещения рядом" (строки 340-380)
  - Восстановлено требование обязательного пересечения для всех слов кроме первого
  - Слова теперь размещаются ТОЛЬКО по совпадающим буквам

### Результат:
- Сканворды имеют компактную структуру с пересечениями
- Каждое слово (кроме первого) обязательно пересекается с хотя бы одним другим словом
- Более традиционная и понятная структура сканворда

## Проблема 2: Стрелки указывают только влево

### Что было не так:
Все стрелки в clue-клетках указывали влево, независимо от направления слова.

### Что исправлено:
- **Файл**: `src/components/Cell.tsx`
- **Изменения**:
  1. Добавлена функция `getArrowStyle()` для расчёта позиции стрелки
  2. Стрелка теперь позиционируется абсолютно и "залезает" в соседнюю клетку
  3. Стрелка поворачивается в соответствии с направлением слова:
     - `right` → стрелка справа, указывает вправо
     - `left` → стрелка слева, указывает влево
     - `down` → стрелка снизу, указывает вниз
     - `up` → стрелка сверху, указывает вверх
     - `down-right` → стрелка в правом нижнем углу, указывает по диагонали
     - `down-left` → стрелка в левом нижнем углу, указывает по диагонали
     - `up-right` → стрелка в правом верхнем углу, указывает по диагонали
     - `up-left` → стрелка в левом верхнем углу, указывает по диагонали

### Технические детали:
```typescript
const getArrowStyle = () => {
  const offset = 8; // Насколько стрелка "залезает" в соседнюю клетку
  
  switch (cell.direction) {
    case 'right':
      return { right: `-${offset}px`, top: '50%', transform: 'translateY(-50%)' };
    case 'down':
      return { bottom: `-${offset}px`, left: '50%', transform: 'translateX(-50%) rotate(90deg)' };
    // ... остальные направления
  }
};
```

### Результат:
- Стрелки визуально указывают направление слова
- Стрелка "залезает" в клетку, откуда начинается слово
- Более интуитивное понимание направления для игрока
