# Исправление проблемы: Clue-клетка залезает в область ввода

## Дата: 2026-03-01

## Проблема

Блок вопроса (clue-клетка) в некоторых случаях залезал в область ввода слова, перекрывая буквы.

## Корень проблемы

В функции `canPlaceWord` отсутствовала проверка, что clue-клетка не находится:
1. Внутри другого уже размещённого слова
2. На продолжении другого слова (сразу после его конца или перед началом)
3. Внутри текущего слова, которое мы пытаемся разместить

### Пример проблемы

```
Слово 1: КОШКА (горизонтально, позиция y=10)
Слово 2: КОТ (вертикально, пересекается по букве К)

Проблема: Clue для слова КОТ мог оказаться на позиции буквы О или Ш из слова КОШКА
```

## Решение

Добавлены три проверки в функцию `canPlaceWord`:

### 1. Проверка: Clue-клетка не внутри другого слова

```typescript
// ВАЖНО: Проверяем, что clue-клетка не находится внутри другого слова
for (const pw of placedWords) {
  const pwVector = getWordDirectionVector(pw.direction);
  for (let i = 0; i < pw.word.length; i++) {
    const pwX = pw.startX + pwVector.dx * i;
    const pwY = pw.startY + pwVector.dy * i;
    if (pwX === clueX && pwY === clueY) {
      return false; // Clue-клетка находится внутри другого слова
    }
  }
}
```

### 2. Проверка: Clue-клетка не на продолжении другого слова

```typescript
// Проверяем, что clue-клетка не находится на продолжении другого слова
// (сразу после конца или сразу перед началом)
const pwEndX = pw.startX + pwVector.dx * pw.word.length;
const pwEndY = pw.startY + pwVector.dy * pw.word.length;
const pwBeforeX = pw.startX - pwVector.dx;
const pwBeforeY = pw.startY - pwVector.dy;

if ((clueX === pwEndX && clueY === pwEndY) || (clueX === pwBeforeX && clueY === pwBeforeY)) {
  return false; // Clue-клетка находится на продолжении другого слова
}
```

### 3. Проверка: Clue-клетка не внутри текущего слова

```typescript
// ВАЖНО: Проверяем, что clue-клетка не находится внутри текущего слова
for (let i = 0; i < len; i++) {
  const wordX = startX + vector.dx * i;
  const wordY = startY + vector.dy * i;
  if (wordX === clueX && wordY === clueY) {
    return false; // Clue-клетка находится внутри текущего слова
  }
}
```

## Результат

✅ Clue-клетка больше не залезает в область ввода слова  
✅ Clue-клетка не находится внутри других слов  
✅ Clue-клетка не находится на продолжении других слов  
✅ Clue-клетка не находится внутри текущего слова  
✅ Сканворд генерируется корректно с 25-30 словами  
✅ Проект успешно собран

### Тестовые сценарии:

1. **Clue-клетка внутри другого слова** - ✅ Блокируется
2. **Clue-клетка на продолжении другого слова** - ✅ Блокируется
3. **Clue-клетка внутри текущего слова** - ✅ Блокируется
4. **Clue-клетка в правильной позиции** - ✅ Разрешается

### Пример корректного размещения:

```
        ↓
[clue] [К][О][Ш][К][А]
              ↓
        [clue][Р][Ы][Б][А]
```

- Clue для "КОШКА" слева от слова - правильно
- Clue для "РЫБА" сверху от слова - правильно
- Ни одна clue-клетка не залезает в область ввода

Проблема полностью решена. Clue-клетки теперь всегда находятся в правильных позициях и не перекрывают область ввода слов.
