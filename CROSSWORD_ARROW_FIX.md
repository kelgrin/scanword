# Исправления логики генератора сканвордов

## Дата: 2026-03-01

## Внесённые изменения

### 1. Стрелка теперь указывает от clue-клетки к первой букве слова

**Проблема:** Стрелка указывала направление слова (вправо или вниз), а не направление от clue-клетки к первой букве.

**Решение:**
- В `wordGenerator.ts` изменена логика установки направления стрелки:
  ```typescript
  // Было:
  const arrowDirection = pw.direction === 'horizontal' ? 'right' : 'down';
  
  // Стало:
  const arrowDirection = pw.clueDirection;
  ```
- Теперь стрелка указывает именно туда, где находится первая буква слова

### 2. Поддержка всех 8 направлений стрелки

**Проблема:** Компонент Cell.tsx поддерживал только 4 направления (вверх, вниз, влево, вправо).

**Решение:**
- Добавлена поддержка диагональных направлений в `Cell.tsx`:
  - `up-right` (вверх-вправо) - стрелка повёрнута на 45°
  - `up-left` (вверх-влево) - стрелка повёрнута на -45°
  - `down-right` (вниз-вправо) - стрелка повёрнута на -45°
  - `down-left` (вниз-влево) - стрелка повёрнута на 45°

### 3. Проверка: на одной линии не может быть двух слов в одном направлении

**Проблема:** Два слова могли идти подряд на одной линии, что создавало путаницу.

**Решение:**
- Добавлена проверка в `canPlaceWord()`:
  - Если оба слова горизонтальные и на одной строке - проверяется, не идут ли они подряд
  - Если оба слова вертикальные и на одном столбце - проверяется, не идут ли они подряд
  - Если слова идут подряд без пересечения - размещение блокируется

```typescript
// Проверяем, находятся ли слова на одной линии
if (direction === 'horizontal') {
  if (pw.startY === startY) {
    // На одной строке - проверяем, не продолжаются ли они
    if (!hasIntersection) {
      if ((pwEndX + 1 === startX) || (wordEndX + 1 === pw.startX)) {
        return false; // Слова идут подряд на одной линии
      }
    }
  }
}
```

✅ Слова могут пересекаться, но не могут идти подряд без пересечения
