# Исправление багов с clue-клетками

## Дата: 2026-03-01

## Проблема 1: Clue-клетка перекрывает буквы слова

### Описание бага:
Клетка с вопросом (clue cell) стояла в том месте, куда нужно вводить букву, и слово нельзя было закончить из-за этого.

### Корень проблемы:
В функции `canPlaceWord` в файле `src/services/wordGenerator.ts` отсутствовала проверка, что clue-клетки не перекрывают буквы **текущего** слова, которое мы пытаемся разместить.

Проверялись только:
- ✅ Clue-клетки не заняты буквами других слов
- ✅ Clue-клетки не заняты другими clue-клетками
- ✅ Clue-клетки не находятся в клетках, которые являются буквами других слов
- ❌ **ОТСУТСТВОВАЛА:** Проверка, что clue-клетки не перекрывают буквы текущего слова

### Решение:
Добавлена проверка в функцию `canPlaceWord` (строки 232-240):

```typescript
// ВАЖНО: Проверяем, что clue-клетки не перекрывают буквы ТЕКУЩЕГО слова
for (let i = 0; i < len; i++) {
  const wordX = startX + vector.dx * i;
  const wordY = startY + vector.dy * i;
  for (const cluePos of cluePositions) {
    if (wordX === cluePos.x && wordY === cluePos.y) {
      return false;
    }
  }
}
```

## Проблема 2: Clue-клетка стоит на второй клетке активной области

### Описание бага:
Часто клетка с вопросом стояла на второй клетке активной области, куда надо вводить слово, вместо того чтобы быть перед первой буквой.

### Корень проблемы:
В функции `findPossiblePlacements` (строки 293-332) clueDirection выбирался случайно из всех 8 направлений:
```typescript
const clueDirections: ClueDirection[] = ['left', 'right', 'up', 'down', 'up-left', 'up-right', 'down-left', 'down-right'];

for (const clueDirection of clueDirections) {
  // ...
}
```

Это приводило к тому, что clue-клетка могла оказаться в любом направлении от слова, включая неправильные позиции (например, справа от слова, когда слово идёт вправо).

### Решение:
ClueDirection теперь определяется автоматически на основе направления слова (строки 305-308):

```typescript
// ВАЖНО: clueDirection определяется автоматически на основе direction
// Для horizontal (вправо) → clue должен быть СЛЕВА (left)
// Для vertical (вниз) → clue должен быть СВЕРХУ (up)
const clueDirection: ClueDirection = direction === 'horizontal' ? 'left' : 'up';
```

Убран перебор всех 8 направлений clueDirections.

## Логика размещения clue-клеток

### Правильная логика:
- **Horizontal (вправо):** clue-клетка должна быть СЛЕВА от первой буквы слова
  - Слово: `К О Ш К А` (направление →)
  - Clue: `[?]` `К О Ш К А`
  - Стрелка указывает вправо (→)

- **Vertical (вниз):** clue-клетка должна быть СВЕРХУ от первой буквы слова
  - Слово: `К` (направление ↓)
  - Clue: `[?]`
  - Буквы: `О`
           `Ш`
           `К`
           `А`
  - Стрелка указывает вниз (↓)

### Неправильная логика (до исправления):
- Clue-клетка могла быть в любом из 8 направлений
- Clue-клетка могла перекрывать буквы слова
- Результат: слово нельзя было заполнить
