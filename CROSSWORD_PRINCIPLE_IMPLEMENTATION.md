### 2. Добавлена проверка на слипание слов

**Проблема:** Слова могли слипаться без пересечения, что нарушало принцип сканворда.

**Решение:** Добавлена проверка перпендикулярных соседей для каждой клетки слова.

### 3. Правильный принцип сканворда

**Что реализовано:**

✅ **Clue-клетка ПЕРЕД словом:**
- Для горизонтального слова: слева от первой буквы
- Для вертикального слова: сверху от первой буквы
- Clue-клетка не залезает в область ввода

✅ **Все буквы принадлежат словам:**
- Каждое слово размещается с пересечением по общим буквам
- Нет "лишних" букв - все буквы входят в слова

✅ **Слова не слипаются:**
- Проверка перпендикулярных соседей для каждой клетки
- Если соседняя клетка содержит букву, это должно быть пересечение
- Если это не пересечение - размещение блокируется

✅ **Пересечения образуют новые слова:**
- Слова размещаются так, чтобы пересечения букв образовывали новые слова
- Каждое пересечение проверяется на совпадение букв

## Как работает алгоритм

### Шаг 1: Размещение первого слова
- Берётся самое длинное слово из пула
- Размещается горизонтально в центре сетки
- Clue-клетка размещается слева от первой буквы

### Шаг 2: Размещение остальных слов
Для каждого следующего слова:
1. Ищутся все возможные пересечения с уже размещёнными словами
2. Для каждого пересечения проверяется:
   - Совпадают ли буквы в точке пересечения
   - Не залезает ли clue-клетка в область ввода
   - Не слипаются ли слова (проверка перпендикулярных соседей)
   - Все клетки слова помещаются в сетку
3. Выбирается лучшее размещение (больше пересечений, ближе к центру)
4. Слово размещается с clue-клеткой перед ним

### Шаг 3: Проверка на слипание
Для каждой клетки слова:
- Проверяются перпендикулярные соседи (сверху/снизу для horizontal, слева/справа для vertical)
- Если сосед содержит букву, проверяется, является ли это пересечением
- Если это не пересечение - слова слипаются, размещение блокируется

## Пример структуры сканворда

```
        ↓
[clue] [К][О][Ш][К][А]
              ↓
        [clue][Р][Ы][Б][А]
```

- Первое слово "КОШКА" горизонтально, clue слева
- Второе слово "РЫБА" вертикально, пересекает "КОШКА" по букве "К"
- Clue для "РЫБА" сверху от первой буквы "Р"
- Слова не слипаются - между ними есть пересечение
