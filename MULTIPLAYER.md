# 🎮 Мультиплеер для Сканворда

Полноценный мультиплеер с комнатами, синхронизацией в реальном времени и чатом.

## 🚀 Настройка базы данных

### 1. Выполните SQL-скрипт в Supabase

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard/)
2. Перейдите в ваш проект
3. Откройте **SQL Editor** (иконка терминала в левом меню)
4. Скопируйте содержимое файла `supabase-schema.sql`
5. Вставьте в редактор и нажмите **Run**

Это создаст следующие таблицы:
- `game_rooms` — комнаты с кроссвордами
- `players` — игроки в комнатах
- `game_state` — состояние букв (синхронизация)
- `chat_messages` — сообщения чата

### 2. Включите Realtime

SQL-скрипт уже включает Realtime для всех таблиц. Проверить можно в **Database** → **Replication**.

## 🎯 Как использовать

### Создание комнаты

1. Нажмите кнопку **"Мультиплеер"** в шапке
2. Выберите **"Создать комнату"**
3. Введите ваше имя
4. Нажмите **"Создать комнату"**
5. Скопируйте 6-значный код комнаты
6. Отправьте код другу

### Присоединение к комнате

1. Нажмите кнопку **"Мультиплеер"** в шапке
2. Выберите **"Присоединиться"**
3. Введите ваше имя
4. Введите код комнаты (например: `ABC123`)
5. Нажмите **"Присоединиться"**

### Игра

- Оба игрока видят один и тот же кроссворд
- При вводе буквы она мгновенно появляется у другого игрока
- Цветные индикаторы показывают, кто какой игрок
- В левом нижнем углу доступен чат для общения

## 💬 Чат

- Нажмите на иконку чата в левом нижнем углу
- Введите сообщение и нажмите Enter
- Сообщения синхронизируются в реальном времени
- История сохраняется (до 100 последних сообщений)

## 🔧 Технические детали

### Синхронизация

Используется **Supabase Realtime** для мгновенной синхронизации:
- При вводе буквы → сохраняется в БД → Realtime отправляет обновление → UI другого игрока обновляется
- Задержка: ~100-300мс

### Структура данных

```typescript
// Комната
{
  id: UUID,
  room_code: "ABC123",
  crossword_data: CrosswordData,
  player_count: 2,
  is_active: true
}

// Состояние буквы
{
  room_id: UUID,
  player_id: UUID,
  cell_id: "c1-2",
  letter: "К"
}

// Сообщение чата
{
  id: UUID,
  room_id: UUID,
  player_id: UUID,
  player_name: "Игрок1",
  message: "Привет!"
}
```

### Ограничения

- Максимум 2 игрока в комнате
- Код комнаты: 6 символов (буквы и цифры)
- История чата: 100 последних сообщений
- Комнаты не удаляются автоматически (можно добавить cron job)

В файле `src/services/multiplayerApi.ts`:

```typescript
export function generateRoomCode(): string {
  const chars = 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789';
  let code = '';
  for (let i = 0; i < 6; i++) { // Измените 6 на нужную длину
    code += chars[Math.floor(Math.random() * chars.length)];
  }
  return code;
}
```

## 🐛 Решение проблем

### "Комната не найдена"

- Проверьте, что код введен правильно (без пробелов)
- Убедитесь, что комната активна (`is_active = true`)
- Проверьте, что SQL-скрипт выполнен

### "Буквы не синхронизируются"

- Проверьте, что Realtime включен для таблиц
- Откройте консоль браузера (F12) и проверьте ошибки
- Убедитесь, что оба игрока в одной комнате

### "Чат не работает"

- Проверьте таблицу `chat_messages` в Supabase
- Убедитесь, что Realtime включен для этой таблицы
- Проверьте политики RLS

## 📊 Мониторинг

### Просмотр активных комнат

```sql
SELECT 
  room_code,
  player_count,
  created_at,
  is_active
FROM game_rooms
WHERE is_active = true
ORDER BY created_at DESC;
```

### Очистка старых комнат

```sql
-- Удалить комнаты старше 7 дней
DELETE FROM game_rooms
WHERE created_at < NOW() - INTERVAL '7 days';
```

## 🔐 Безопасность

Текущая реализация использует открытые политики RLS для простоты. Для продакшена рекомендуется:

1. Добавить аутентификацию пользователей
2. Ограничить доступ к комнатам только для участников
3. Добавить rate limiting для предотвращения спама
4. Валидировать данные на стороне сервера
