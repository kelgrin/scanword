# 🎮 Мультиплеер для Сканворда

Полноценный мультиплеер с комнатами, синхронизацией в реальном времени, чатом и цветовой индикацией игроков.

## ✨ Новые возможности

### 🎨 Цветовая индикация игроков
- Каждый игрок имеет свой уникальный цвет
- Буквы, введенные разными игроками, отображаются разными цветами
- Цвет сохраняется в базе данных и синхронизируется между игроками
- При обновлении страницы цвета сохраняются

### 🧹 Автоматическая очистка комнат
- При выходе из комнаты игрока удаляются из базы данных
- Если оба игрока покинули комнату, она автоматически удаляется
- Добавлено поле `last_activity` для отслеживания активности
- Функция `cleanupRoom()` полностью очищает все связанные данные

### 💬 Улучшенный чат
- Исправлена проблема с отображением сообщений между разными городами
- Realtime подписка работает корректно через Supabase
- История сообщений загружается при подключении
- Сообщения синхронизируются в реальном времени

### 📊 Синхронизация прогресса
- Прогресс решения кроссворда синхронизируется между игроками
- Слово засчитывается как угаданное, когда все буквы правильные (независимо от того, кто их ввел)
- Оба игрока видят одинаковый прогресс

## 🚀 Настройка базы данных

### 1. Выполните SQL-скрипт в Supabase

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard/)
2. Перейдите в ваш проект
3. Откройте **SQL Editor** (иконка терминала в левом меню)
4. Скопируйте содержимое файла `supabase-schema.sql`
5. Вставьте в редактор и нажмите **Run**

Это создаст следующие таблицы:
- `game_rooms` — комнаты с кроссвордами
- `players` — игроки в комнатах
- `game_state` — состояние букв (синхронизация)
- `chat_messages` — сообщения чата

### 2. Включите Realtime

SQL-скрипт уже включает Realtime для всех таблиц. Проверить можно в **Database** → **Replication**.

## 🎯 Как использовать

### Создание комнаты

1. Нажмите кнопку **"Мультиплеер"** в шапке
2. Выберите **"Создать комнату"**
3. Введите ваше имя
4. Нажмите **"Создать комнату"**
5. Скопируйте 6-значный код комнаты
6. Отправьте код другу

### Присоединение к комнате

1. Нажмите кнопку **"Мультиплеер"** в шапке
2. Выберите **"Присоединиться"**
3. Введите ваше имя
4. Введите код комнаты (например: `ABC123`)
5. Нажмите **"Присоединиться"**

### Игра

- Оба игрока видят один и тот же кроссворд
- При вводе буквы она мгновенно появляется у другого игрока
- Цветные индикаторы показывают, кто какой игрок
- В левом нижнем углу доступен чат для общения
- **Каждый игрок может удалять только свои буквы** - чужие буквы защищены от удаления
- При нажатии Backspace на чужую букву курсор просто перемещается дальше, не удаляя её

## 💬 Чат

- Нажмите на иконку чата в левом нижнем углу
- Введите сообщение и нажмите Enter
- Сообщения синхронизируются в реальном времени
- История сохраняется (до 100 последних сообщений)

## 🔧 Технические детали

### Синхронизация

Используется **Supabase Realtime** для мгновенной синхронизации:
- При вводе буквы → сохраняется в БД → Realtime отправляет обновление → UI другого игрока обновляется
- Задержка: ~100-300мс

### Структура данных

```typescript
// Комната
{
  id: UUID,
  room_code: "ABC123",
  crossword_data: CrosswordData,
  player_count: 2,
  is_active: true
}

// Состояние буквы
{
  room_id: UUID,
  player_id: UUID,
  cell_id: "c1-2",
  letter: "К"
}

// Сообщение чата
{
  id: UUID,
  room_id: UUID,
  player_id: UUID,
  player_name: "Игрок1",
  message: "Привет!"
}
```

### Ограничения

- Максимум 2 игрока в комнате
- Код комнаты: 6 символов (буквы и цифры)
- История чата: 100 последних сообщений
- Комнаты не удаляются автоматически (можно добавить cron job)

## 🐛 Решение проблем

### "Комната не найдена"

- Проверьте, что код введен правильно (без пробелов)
- Убедитесь, что комната активна (`is_active = true`)
- Проверьте, что SQL-скрипт выполнен

### "Буквы не синхронизируются"

- Проверьте, что Realtime включен для таблиц
- Откройте консоль браузера (F12) и проверьте ошибки
- Убедитесь, что оба игрока в одной комнате
- **Важно:** После обновления SQL схемы выполните redeploy приложения

### "Чат не работает между разными городами"

**Решение: Добавлен Polling Fallback**

Если WebSocket не работает (ошибки подключения в консоли), система автоматически переключается на polling:

1. **Автоматическое переключение**: Если WebSocket не подключается в течение 3 секунд, включается polling каждые 2 секунды
2. **Ручная синхронизация**: Нажмите кнопку синхронизации (🔄) в шапке или в чате
3. **Индикатор статуса**: Зелёная точка показывает, что синхронизация активна

**Как это работает:**
- Сначала система пытается подключиться через WebSocket (мгновенная синхронизация)
- Если WebSocket недоступен (preview окружения, firewall, CORS), автоматически включается polling
- Polling проверяет изменения каждые 2 секунды и синхронизирует данные
- Все изменения (буквы, сообщения чата, игроки) синхронизируются одинаково

**Проверка подключения:**
- Откройте консоль браузера (F12)
- Найдите логи `[Multiplayer]` и `[Chat]`
- Если видите "Starting polling fallback" — система работает в режиме polling
- Если видите "WebSocket status: SUBSCRIBED" — работает WebSocket

**Ручная синхронизация:**
Если данные не синхронизируются, нажмите кнопку 🔄 в шапке (для кроссворда) или в чате (для сообщений).

**Проверка Realtime (опционально):**
```sql
-- Проверить, что таблица добавлена в Realtime
SELECT * FROM pg_publication_tables 
WHERE pubname = 'supabase_realtime' 
AND tablename = 'chat_messages';
```

Если таблица не найдена, выполните:
```sql
ALTER PUBLICATION supabase_realtime ADD TABLE chat_messages;
ALTER PUBLICATION supabase_realtime ADD TABLE game_state;
ALTER PUBLICATION supabase_realtime ADD TABLE players;
```

### "Цвета игроков не отображаются"

- Убедитесь, что выполнили обновленный SQL скрипт (добавлено поле `player_color`)
- Проверьте, что в таблице `game_state` есть колонка `player_color`
- Очистите кэш браузера (Ctrl+Shift+R)

### "Прогресс не синхронизируется"

- Прогресс вычисляется локально на основе введенных букв
- Убедитесь, что буквы синхронизируются (см. выше)
- Проверка слов происходит автоматически после каждого изменения

## 📊 Мониторинг

### Просмотр активных комнат

```sql
SELECT 
  room_code,
  player_count,
  created_at,
  is_active
FROM game_rooms
WHERE is_active = true
ORDER BY created_at DESC;
```

### Очистка старых комнат

```sql
-- Удалить комнаты старше 7 дней
DELETE FROM game_rooms
WHERE created_at < NOW() - INTERVAL '7 days';

-- Удалить неактивные комнаты (последняя активность более 1 часа назад)
DELETE FROM game_rooms
WHERE last_activity < NOW() - INTERVAL '1 hour';
```

### Автоматическая очистка при выходе

Когда игрок нажимает "Выйти":
1. Игрок удаляется из таблицы `players`
2. Если в комнате не осталось игроков, вызывается `cleanupRoom()`
3. Удаляются все связанные данные: `game_state`, `chat_messages`, `players`, `game_rooms`

**Ручная очистка конкретной комнаты:**
```sql
-- Замените 'ROOM_ID' на ID комнаты
DELETE FROM game_state WHERE room_id = 'ROOM_ID';
DELETE FROM chat_messages WHERE room_id = 'ROOM_ID';
DELETE FROM players WHERE room_id = 'ROOM_ID';
DELETE FROM game_rooms WHERE id = 'ROOM_ID';
```

3. Добавить rate limiting для предотвращения спама
4. Валидировать данные на стороне сервера
