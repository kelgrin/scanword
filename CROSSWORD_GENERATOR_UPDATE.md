# Изменение логики генератора сканвордов

## Дата: 2026-03-01

## Внесённые изменения

### 1. Clue-клетка может быть в любой из 8 соседних позиций

**Что изменено:**
- Функция `findPossiblePlacements` теперь перебирает все 8 направлений для clue-клетки:
  - `left` (слева)
  - `right` (справа)
  - `up` (сверху)
  - `down` (снизу)
  - `up-left` (сверху-слева)
  - `up-right` (сверху-справа)
  - `down-left` (снизу-слева)
  - `down-right` (снизу-справа)

**Результат:**
- Clue-клетка может быть расположена вокруг первой буквы слова в любом из 8 направлений
- Это создаёт более компактный и интересный сканворд

### 2. Слово пишется только вправо или вниз

**Что осталось:**
- Слова размещаются только горизонтально (вправо) или вертикально (вниз)
- Это стандартная логика для сканвордов

### 3. Clue может занимать 1 или 2 клетки

**Что осталось:**
- Алгоритм пробует clueWidth = 1 и clueWidth = 2
- Это позволяет размещать более длинные вопросы

### 4. Стрелка указывает от clue-клетки к первой букве

**Логика:**
- `clueDirection` указывает направление ОТ clue-клетки К первой букве слова
- Например:
  - `clueDirection = 'right'` → clue-клетка слева, стрелка указывает вправо к первой букве
  - `clueDirection = 'down'` → clue-клетка сверху, стрелка указывает вниз к первой букве
  - `clueDirection = 'down-right'` → clue-клетка сверху-слева, стрелка указывает по диагонали к первой букве

```typescript
function getCluePosition(placed: PlacedWord): { x: number; y: number }[] {
  const clueVector = getClueDirectionVector(placed.clueDirection);
  // Clue-клетка(и) стоят в обратном направлении от clueVector
  // clueDirection указывает направление ОТ clue-клетки К первой букве слова
  const positions = [];
  for (let i = 0; i < placed.clueWidth; i++) {
    positions.push({
      x: placed.startX - clueVector.dx * (i + 1),
      y: placed.startY - clueVector.dy * (i + 1),
    });
  }
  return positions;
}
```
