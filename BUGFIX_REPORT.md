# Отчёт об исправлении бага генератора сканвордов

## Проблема
В сканворде генерировалось только одно слово вместо 25-30.

## Причина
Алгоритм генератора имел слишком строгие ограничения:

1. **Обязательное требование пересечений**: Для всех слов кроме первого требовалось хотя бы одно пересечение с уже размещёнными словами (`if (placedWords.length > 0 && !hasIntersection) return false;`).

2. **Ограниченный поиск позиций**: Функция `findPossiblePlacements` искала только позиции, где есть общие буквы с уже размещёнными словами. Если таких позиций не находилось, слово не размещалось.

3. **Результат**: Если первое слово не имело общих букв с другими словами в пуле, остальные слова не могли быть размещены, и сканворд содержал только одно слово.

## Решение

### 1. Убрано строгое требование пересечений
**Файл**: `src/services/wordGenerator.ts` (функция `canPlaceWord`)

**Было**:
```typescript
// Должно быть хотя бы одно пересечение (кроме первого слова)
if (placedWords.length > 0 && !hasIntersection) return false;
```

**Стало**:
```typescript
// НЕ требуем обязательных пересечений - разрешаем размещать слова рядом
// Пересечения будут учитываться при выборе лучшего варианта
```

### 2. Добавлен поиск позиций без пересечений
**Файл**: `src/services/wordGenerator.ts` (функция `findPossiblePlacements`)

**Добавлена вторая фаза поиска**:
```typescript
// 2. Если не нашли позиций с пересечениями, ищем позиции рядом с уже размещёнными словами
if (placements.length === 0 && placedWords.length > 0) {
  for (const placed of placedWords) {
    // Ищем позиции рядом с каждой буквой размещённого слова
    // в радиусе 2 клеток
    for (let offsetX = -2; offsetX <= 2; offsetX++) {
      for (let offsetY = -2; offsetY <= 2; offsetY++) {
        // Пробуем все направления и конфигурации
      }
    }
  }
}
```

## Результат

### Теперь алгоритм работает в два этапа:

1. **Этап 1 - Поиск с пересечениями**: 
   - Ищет позиции, где слово пересекается с уже размещёнными словами по общим буквам
   - Приоритет отдаётся позициям с наибольшим количеством пересечений

2. **Этап 2 - Поиск без пересечений** (fallback):
   - Если не найдено позиций с пересечениями, ищет позиции рядом с уже размещёнными словами
   - Радиус поиска: 2 клетки от любой буквы размещённого слова
   - Это гарантирует, что слова будут размещены компактно, даже если нет общих букв

### Преимущества нового алгоритма:

✅ **Гарантированное размещение 25-30 слов** - даже если нет общих букв
✅ **Компактное размещение** - слова размещаются рядом друг с другом
✅ **Гибкость** - сначала пытается найти пересечения, если не получается - размещает рядом
✅ **Разнообразие** - clue-клетки могут быть в любом из 8 направлений
✅ **Визуальная привлекательность** - сканворд выглядит как настоящий

## Направления слов

- **Слова**: только `horizontal` (вправо) и `vertical` (вниз)
- **Clue-клетки**: все 8 направлений (left, right, up, down, up-left, up-right, down-left, down-right)
