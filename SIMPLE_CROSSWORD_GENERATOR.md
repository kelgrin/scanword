# Возврат к простой логике генерации сканворда

## Дата: 2026-03-01

## Что было упрощено

Вернулась к исходной простой логике генерации сканворда:

### Основные правила:

1. **Слова размещаются только в двух направлениях:**
   - Горизонтально (→ вправо)
   - Вертикально (↓ вниз)

2. **Clue-клетка (вопрос) всегда находится:**
   - Слева от горизонтального слова
   - Сверху от вертикального слова

3. **Слова пересекаются по общим буквам:**
   - Каждое новое слово должно пересекаться с уже размещёнными
   - Пересечение происходит по совпадающим буквам

4. **Стрелка указывает направление слова:**
   - → для горизонтальных слов
   - ↓ для вертикальных слов

## Пример структуры сканворда

```
        ↓
[clue] [К][О][Ш][К][А]
              ↓
        [clue][Р][Ы][Б][А]
```

- Первое слово "КОШКА" горизонтально, clue слева
- Второе слово "РЫБА" вертикально, пересекает "КОШКА" по букве "К"
- Clue для "РЫБА" сверху от первой буквы "Р"
